Format it as a single fenced code block labelled `FINAL IMAGE PROMPT`, so it can be copied cleanly. Use the labelled-block template from step 1 in order: Format → Concept → Subject → Details → Metal lines → Palette → Layout → Constraints last.

**Length: 180–250 words.** Long enough to carry the full spec, short enough that no single instruction gets diluted. If you are over, cut adjectives before you cut any production rule.

Hard requirements for that prompt:

- Its **first sentence** states this is **flat 2D front-view vector artwork for an enamel pin design** — not a photo, not a mockup. Opening words set the mode for everything after, and this is the failure this design is most prone to.
- It states that **every colour region is enclosed by a metal outline**, with the outer silhouette line heaviest.
- It names the flat colours explicitly and keeps the count inside your ceiling.
- It specifies a centred composition on a **plain flat background** with even margin.
- Any literal text appears in quotes with exact casing, kept to a few characters.
- The exclusion list comes **last**, after every positive descriptor, and leads with the anti-mockup group: no photograph, no 3D render, no perspective, no bevel, no metallic sheen, no drop shadow, no backing card, no hand or garment.

- One prompt only. No variants, no alternates, no commentary after the code block.
