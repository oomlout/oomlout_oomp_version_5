## Part B — the final prompt

End your response with the final image-generation prompt for the chosen set, and nothing after it.

Format it as a single fenced code block labelled `FINAL IMAGE PROMPT`, so it can be copied cleanly. Use the labelled-block template from step 1 in order: Format → Concept → Icons → Layout → Line & fill → Palette → Background → Constraints last.

**Length: 180–250 words.** Long enough to carry the full spec, short enough that no single instruction gets diluted. If you are over, cut icons before you cut any layout or simplification rule — fewer, larger, cleaner badges beat a crowded sheet.

Hard requirements for that prompt:

- Its **first sentence** states this is a **single square sheet of separate small icon badges in flat vector style on a plain flat white background**. Opening words set the mode, and turning this into a scene is the failure it is most prone to.
- It lists the icons explicitly as a numbered list, each with its badge shape.
- It states the **regular grid with equal cell size, even spacing, nothing overlapping, nothing cropped**.
- It says each icon must be **simplified enough to read at about 20 mm**, and caps elements per badge.
- It gives the shared stroke weight and the named palette used across the whole set.
- The exclusion list comes **last**, after every positive descriptor, and leads with no scene, no overlapping badges, no micro text, no fine interior detail.
- It is self-contained: someone pasting it cold, with no memory of this conversation, gets the same image. No "as described above", no "the icons from earlier".
- One prompt only. No variants, no alternates, no commentary after the code block.
