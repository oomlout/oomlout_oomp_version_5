# OOMP documentation

For directory, catalogue or part documentation changes, read
`presentation/README.md`, `presentation/STYLE.md` and
`presentation/CATALOGUE_REFRESH.md`. Keep the base README focused on finding
repositories; local setup belongs in `README_GENERATOR.md`.

Update the generating code and repository configuration together with outputs.
Preserve specialist notes and existing user changes. Lightweight YAML exports
must not gain part README files. The repository audit is a plan and status record,
not authorization to publish changes or rewrite history in other repositories.

The electronic and electronic-project repositories are being maintained elsewhere.
Do not modify `oomp_electronic_version_5` or `oomp_electronic_project_version_5`,
including reinstalling documentation changes that the user has reverted.
Keep them linked in the base directory. Sort that directory by full repository
name/code and use full-detail hardware renders for its gallery.
